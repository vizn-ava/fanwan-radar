# 饭碗雷达 · 评论区点单 02

一个本机运行的真实岗位筛选与分析工具：**写一段要求 → 模型整理并由你确认保存 → 按条件查真实岗位 → 选择岗位进行流式分析**。也可逐项填写或微调。这是本地优先 V1，不是云端账号服务，也不保证能找到符合全部条件的职位。

## 启动

Windows 安装 Python 3.11+ 后，双击 `start-demo.cmd`。

首次启动会创建独立 `.venv` 并安装 `requirements.txt`；随后打开：

http://127.0.0.1:8765

也可以在项目目录手动运行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8765
```

应用无需 Node 或前端编译。画像编辑和可解释匹配在本机完成；AI 分析需要使用者配置自己的 OpenAI 兼容服务及 API Key。未配置时会说明缺少什么，不会假装调用模型。

## 首次准备

首次打开会显示 `First Try` 使用指南，介绍三个工作区域、模型与招聘平台准备、如何试填一段话。关闭后不反复自动弹出，可从顶部随时重看。引导不会自动保存示例、搜索职位或生成虚构结果；本地浏览器仅记住非敏感的引导状态。

1. 打开页面的模型设置，填写兼容地址和自己的 API Key，读取服务实际提供的模型列表、选择模型并测试连接。留空 Key 不会删除已保存的 Key；移除要使用独立按钮。
2. 使用 BOSS 时，点击打开专用登录窗口，**本人**在那个窗口登录。它和日常浏览器不是同一份登录状态；连接就绪不等于已经登录。
3. 填写并保存自己的城市、岗位方向、工资、保险与休息要求。旧版迁移来的默认条件需要本人确认。未提供的学历、经验和技能保持空白。

评论区需求示例是“郑州、月薪六千以上、双休、五险一金”。“六千”不能擅自理解为固定底薪，“双休”不保证固定周末；示例不代表已找到符合要求的工作，也不提供虚构的个人经历。

## 日常使用

1. 在左侧用一整段话描述情况与要求，点击模型整理，核对提取值及对应原话，确认填入后保存。未说过的学历、经验、技能不会作为默认值补上；不明确的部分会列为问题。本工具不另存原段落、不写入浏览器持久存储；模型服务的数据政策由服务商约定。
2. 需要时展开逐项微调。条件可设为硬性、偏好或不参与匹配；个人已有技能是能力参考，不等于岗位必须出现同一个关键词。
3. 选择已接通的真实来源，查看检索范围，按画像查岗位。平台前筛只使用实际支持的参数，保险、排班等条件在取得原文后再核对。
4. 搜索是有进度、可取消的后台任务；先显示真实列表，再补少量详情。列表不等于完整 JD；未知项不补造。旧结果和本轮结果明确区分。
5. 在中间查看薪资、地点、匹配依据与原始来源链接。原链接在新标签打开时，平台可能要求在该浏览器重新登录。
6. 选择最多五份岗位，让右侧比较适合程度、技能缺口或该问招聘方什么。文字来自模型真实增量流，不是收到完整答案后的模拟打字；可随时停止。
7. 右侧分析不会修改画像、发起搜索、联系招聘者或投递；左侧整理也只产生待确认草稿，保存是独立的明确操作。刷新后已保存画像、最近分析对话和真实结果仍在本机。

若模型把大小周误说成“每周都休两天”等明确矛盾，回答校核会停止该轮、提示原因且不保存；可以看岗位卡的规则依据和原文，或重新提问。校核只覆盖有限的常见冲突，不是完整事实核验。

本版不需要上传简历。旧版简历接口仅留作兼容，历史简历全文默认不会发送给模型。

## 真实数据来源

### BOSS：本人登录后采集

在项目目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\打开BOSS登录.ps1
```

脚本优先使用 Chrome，没有 Chrome 时使用 Edge，打开一个独立的浏览器配置目录和仅监听本机的 CDP 端口 9222。请本人完成 BOSS 登录，然后在网页选择“BOSS 登录采集”。

- 不复制日常浏览器的登录状态，不读取或导出 Cookie 文件。
- 浏览器会管理自身临时配置目录中的会话；目录位于 `%TEMP%\fanwan-radar-chrome`。用完可关闭该专用浏览器，之后自行删除该目录以清除其本地登录状态。
- 不自动启动扫码、不绕过验证码或访问限制；遇到登录或风控会停止。
- 每轮按有限城市和关键词检索有限候选，只补少量完整 JD，并保留已经拿到的部分结果，不做全站抓取。
- 启动前已占用的 9222 端口不会被强行关闭或接管；可通过 `JOB_CDP_PORT` 另设端口。
- 已有本人登录后的真实联调记录；后续每轮仍取决于登录、平台可访问性及页面结构。遇到验证码或限制会停止，由本人处理，不绕过验证。

### 国家大学生就业服务平台

读取[平台公开岗位](https://www.ncss.cn/student/jobs/index.html)的真实列表与可用详情，无需把招聘平台 Cookie 交给模型。

- 主要面向高校和毕业生，需核对招聘对象与岗位有效性，不等于适合所有求职者。
- 部分转载岗位详情只有标题，仍标为列表信息，不能冒充完整 JD。
- 来源仅披露省份时不把查询城市当作岗位事实；没有明确福利、固定底薪、休息安排则保持未知。
- 猎聘、智联本轮未接通，旧公开搜索摘要通道也未作为正式来源启用；不会伪装成多平台均已支持。

### 手动导入

录入已实际查看的岗位时，必须提供真实来源链接与原文，标记为“用户导入、未独立核实”。只提取原文明确列出的公开联系方式，不推测隐藏号码或拼接邮箱。正常页面不提供虚构演示来源，也不会在失败时混入样例。

## 如何分析

当前匹配是可解释的确定性规则，不把排序分数当作录用概率：

- 地点、固定底薪/招聘标价、双休、五险一金、学历、工作经验、目标岗位分别给出结果与依据。
- 每项只有“符合 / 不符合 / 未知”。任何硬性不符都优先归为不符，有未知项则待确认。
- “五险”不代表有公积金；薪资上限不代表能拿到的工资；大小周不等于固定双休。
- 目前未实现通勤地图、工商征信、岗位真实性核验、OCR、自动投递、私域联系方式查找或录用保证。
- 未提供候选人的学历、经验时，不替其编造；支持工时、夜班、轮班、上几休几、工作类型等独立条件。
- 短文本规则存在语言覆盖边界，画像、原文和沟通草稿都应由本人复核。

## 模型与隐私

推荐在页面配置；高级用户也可在启动前设置进程环境变量：

```powershell
$env:JOB_LLM_BASE_URL = 'https://你的服务地址/v1'
$env:JOB_LLM_MODEL = '你实际可用的模型名称'
$env:JOB_LLM_API_KEY = '仅在本机配置，不发到聊天或代码仓库'
.\start.ps1
```

`.env.example` 只是字段示例，程序不会自动加载 `.env`。

模型用于分析已经保存的条件与已有真实岗位；匹配核对仍保留可检查的原文依据。未配置、鉴权失败或流中断会明确报错，没有本地规则冒充模型的自动回退。

Windows 下 Key 用当前用户的 DPAPI 加密，存于 `data/model-key.dpapi`，不返回给前端、不进入浏览器存储或源码包。非 Windows 平台仅保留会话内 Key。岗位分析会将必要画像、有限岗位原文和最近上下文发送至你配置的模型服务；姓名、联系方式与历史简历全文默认不作为岗位分析上下文。左侧要求整理会发送你主动输入的描述，请只提供求职所需信息，不要填身份证、银行卡等无关敏感资料。

原生阿里云兼容接口的 Qwen3 日常分析默认关闭深度思考以减少首字等待；不会把服务专用参数发送到其他兼容接口。TLS 校验保持启用，重复请求复用证书配置，而不是用关闭证书校验来提速。

## 本地数据

画像、最近 40 条对话、真实岗位及任务记录保存在 `data/local.sqlite3`。模型配置单独管理。清除业务数据需要确认，清除后进行中的旧请求不能把数据写回来；模型 Key 需要独立移除。升级备份在本机 `data/backups`，不应分发。

服务只绑定 `127.0.0.1`，有同源写入检查与 Host 校验。它不是已部署的多人账号系统，不应直接暴露到公网。

更新代码后需重启原服务。启动器会核对实际加载的代码指纹，避免新页面误连旧接口；提示旧版本正在运行时，关闭原服务窗口后重启，不需要删除数据。

首页与静态资源不保留旧缓存，脚本和样式地址带代码版本号。已经打开的旧标签仍需刷新或重新打开；请先保存正在修改的条件，未保存的段落原文不写入浏览器持久存储。
